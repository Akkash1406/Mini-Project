# Government Scheme Search API

A lightweight FastAPI backend for searching government schemes. No database required — schemes are stored in `data/schemes.json` and loaded into memory.

## Run locally

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

Visit `http://localhost:8000/docs` for interactive API docs (auto-generated by FastAPI).

## Endpoints

- `GET /schemes` — list all schemes. Supports query params:
  - `q` — keyword search (name, eligibility, benefits, category)
  - `category` — filter by category
  - `state` — filter by state
  - `page`, `page_size` — pagination
- `GET /schemes/{id}` — get one scheme by ID
- `GET /schemes/categories` — list all distinct categories (for building a filter dropdown)
- `GET /schemes/states` — list all distinct states (for building a filter dropdown)

## Adding real scheme data

1. Open `schemes_template.xlsx` and fill in rows using the sample row as a guide.
   Columns: `id, name, category, state, eligibility, benefits, how_to_apply, official_link`
2. Run the converter:
   ```bash
   python convert_excel_to_json.py schemes_template.xlsx
   ```
3. Restart the server — it will pick up the new `data/schemes.json`.

## Connecting your frontend

Point your frontend's API base URL to wherever this is deployed, e.g.:
```js
fetch("http://localhost:8000/schemes?q=farmer")
```

CORS is currently open to all origins (`allow_origins=["*"]`) for easy local development.
**Before deploying to production**, restrict this in `main.py` to your actual frontend domain.
